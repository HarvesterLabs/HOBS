**出来高活動の時間的変化に関する研究**

- 研究状態：探索段階・仮説検証中
- 文書版：v0.1
- 親プロジェクト：HOBS
- 保存場所：`docs/MT5/VOL-ActivityTime/`

## 1. 研究目的

VOL-ActivityTimeは、出来高活動が時間の経過とともにどのように変化するかを観測するための暫定的な研究概念である。

本研究の主目的は、出来高状態の時間的な変化を識別し、記述することである。

現時点では、次のような状態変化を観測候補として扱う。

- 活性化
- 継続
- 減衰
- 再活性化
- 正常化

これらの分類や定義は、まだ確定していない。

また、VOL-ActivityTimeが独立した観測概念として成立することや、価格方向を予測できることを前提としない。

## 2. 中心となる研究課題

**出来高活動は時間の経過とともにどのように変化し、その変化を一貫した方法で観測・記録できるか。**

価格の動きは、背景情報または後続確認の対象として扱う。ただし、出来高活動そのものの観測とは分離して記録する。

## 3. 研究原則

### 3-1. 解釈より先に観測する

意味づけや原因の推定を行う前に、チャート上で確認できる事実を記録する。

### 3-2. 出来高状態と価格方向を分離する

短時間足における出来高の活性化と、長時間足における価格方向は、別々の観測項目として記録する。

### 3-3. 因果関係を早期に確定しない

出来高の変化と価格反応が近い時刻に発生しても、それだけで出来高が価格反応を引き起こしたとは判断しない。

### 3-4. 定義と記録条件を一貫させる

状態の境界、判定基準、時間足、記録方法は、定量的な結論を出す前に明文化する。

### 3-5. 不確実性を保持する

記録では、次の内容を区別する。

- 観測事実
- 仮説
- 解釈
- 未検証の前提

未確定の内容を確定事項として扱わない。

### 3-6. 発生しなかった事象や欠損も記録する

目立つ事例だけを選択して記録することを避ける。必要に応じて、事象が発生しなかったケースやデータが不足しているケースも残す。

## 4. 出来高状態の暫定分類

以下は現時点での観測候補であり、確定した分類ではない。

- **活性化**：定義された基準と比較して、出来高活動が増加する状態。
- **継続**：活性化した状態が一定時間維持される状態。
- **減衰**：活性化または継続の後に、出来高活動が低下する状態。
- **再活性化**：減衰または低活動の後に、出来高活動が再び増加する状態。
- **正常化**：出来高活動が定義された基準範囲へ戻る状態。

各状態の定義、測定方法、判定境界は、今後の観測と検証を通じて検討する。

## 5. 観測項目の分離

研究記録では、以下の観測軸を混同しない。

### 5-1. 出来高の事実

- 観測された出来高
- 相対出来高
- 直前との変化
- 状態の継続時間
- 出来高状態の分類

### 5-2. 時間の情報

- 日付と時刻
- 時間帯・市場セッション
- 使用した時間足
- 関連する経済指標などのイベント情報

### 5-3. 価格の情報

- 価格方向
- 価格構造
- 出来高変化の前後における価格反応

### 5-4. 参照情報

- VWAP
- AVWAP
- メモリーゾーン
- HOBSおよびSLBの関連観測

VWAPとAVWAPは、出来高加重による価格・平均コストの参照情報である。経過時間や出来高状態の継続時間そのものを表す指標ではない。

### 5-5. 解釈

- 仮説
- 考えられる説明
- 後続観測による確認結果
- 未解決の疑問

解釈は観測事実とは別に記録する。

## 6. 時間足の運用方針

初期段階では、以下の時間足を観測候補とする。

- **15分足**：主観測時間足
- **30分足**：状態の継続性・連続性の確認
- **1時間足**：広い時間軸での背景確認
- **5分足**：局所的な変化の詳細確認
- **1分足**：補助観測。ノイズの影響に注意する

すべての時間足を毎回使用する必要はない。使用した時間足と、その選択理由を記録する。

## 7. データ上の制約

TradingViewで表示されるFXの出来高は、ブローカー固有のティック出来高である場合があり、市場全体の実取引量を示すとは限らない。

出来高バーの色やローソク足の色を、そのまま実際の買い出来高・売り出来高の優勢と解釈しない。

ブローカー、データ配信元、時間足、ローソク足の生成条件によって表示内容が異なる可能性がある。

## 8. CASE記録方針

各事例には一意のCASE IDを付与し、可能な範囲で以下を記録する。

- CASE ID
- 通貨ペア・銘柄
- データ配信元
- 日付とタイムゾーン
- 使用時間足
- 観測時刻
- 出来高状態と確認できた変化
- 価格の状況（出来高記録とは分離）
- VWAP・AVWAPなどの参照情報
- 仮説（設定した場合）
- 後続の価格反応・照合結果
- 証拠画像などの参照先
- 記録の状態
- 未解決の疑問

事例は暫定状態のまま保存してよい。

時間的に近接して発生したという事実だけで、因果関係を確定しない。

## 9. 現在の研究状態

**現在の状態：探索段階**

本研究では、出来高活動の時間的な変化を一貫して記述できるか、またVOL-ActivityTimeという概念に独立した観測価値があるかを検討する。

現時点では、以下の事項は確定していない。

- 最終的な概念定義
- 状態分類と判定境界
- 数値化の方法
- 価格予測能力
- MT5での実装仕様

## 10. 開発方針

**研究を先に進め、実装はその後に行う。**

MT5への実装は、少なくとも次の事項が検討・明文化され、検証可能になった段階で開始する。

- 観測対象となる数量
- 出来高状態の定義
- 期待される動作
- 判定条件
- 検証手順

プログラムが正常にコンパイルできたことだけでは、研究概念の妥当性が証明されたことにはならない。
