# 観測事例（Cases）

VOL-ActivityTimeの研究で記録する観測事例を保存する場所。

## 記録方針

- 観測した事実と仮説を分けて記録する。
- 出来高状態の時間変化を中心に記録する。
- 価格の動きやVWAP・SLBの情報は、別の観測項目として扱う。
- 観測時点で分からない情報は、推測で補わない。
- 仮説は検証前に確定事項として扱わない。
